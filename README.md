# MetaCheck

Веб-чекер метаданих: витягує все, що є у файлі (EXIF, XMP, IPTC, ICC, GPS, MakerNotes, QuickTime, ID3, PDF, Office…), оцінює ризики для приватності та знаходить аномалії.

## Запуск

Потрібен лише Node.js 22+ (ExifTool для Windows постачається разом із пакетом `exiftool-vendored`).

```bash
npm install
npm run dev:server   # API на http://127.0.0.1:4000
npm run dev:web      # UI на http://localhost:5173
```

### Доступ з інших пристроїв у Wi-Fi

```bash
npm run lan
```

Збирає фронтенд і запускає один сервер на всіх мережевих інтерфейсах, порт 4000. У консолі буде список адрес — відкривай ту, що позначена `Wi-Fi`, напр. `http://192.168.0.172:4000`, з будь-якого пристрою в тій самій мережі.

- Спершу зареєструйся сам: перший обліковий запис стає адміністратором.
- Реєстрація відкрита для всіх, хто бачить сторінку. Вхід і реєстрація обмежені 10 спробами за 5 хвилин з однієї адреси.
- Зʼєднання — звичайний HTTP без шифрування: у спільній чи публічній мережі паролі й файли можна перехопити. Використовуй лише в довіреній мережі.
- Windows може спитати дозвіл для Node.js у брандмауері — дозволь для приватних мереж.

Дані (SQLite + файли) лежать у `data/`. Тестовий файл з GPS/автором: `node samples/make-sample.mjs`.

## Спільна робота

- Вхід за логіном і паролем. Перший зареєстрований користувач стає адміністратором і має права власника в усіх проєктах.
- Кожен файл належить проєкту. Ролі в проєкті:

  | Роль | Може |
  |---|---|
  | Глядач | бачити файли, метадані, коментарі, журнал; скачувати й експортувати |
  | Коментатор | + коментувати, закривати обговорення, ставити мітки |
  | Редактор | + завантажувати, редагувати метадані, відкочувати, видаляти й переносити файли |
  | Власник | + керувати учасниками, перейменовувати й видаляти проєкт |

- Хто не в проєкті, отримує 404 (а не 403) — навіть існування файлу не розкривається. Події SSE і згадки отримують лише ті, хто має доступ до файлу.
- У проєкті завжди лишається хоча б один власник. Видалити можна лише порожній проєкт. Вийти з проєкту може будь-хто.
- Файли, завантажені до появи проєктів, автоматично потрапили в проєкт «Загальний».
- Усі `/api`-маршрути, крім `/api/health` і `/api/auth/*`, вимагають сесії.
- Коментарі до файлу або до конкретного поля метаданих (💬 у таблиці), відповіді, «Закрити обговорення» / «Відкрити знову». Нова відповідь автоматично відкриває закрите обговорення.
- `@логін` згадує колегу: автодоповнення в полі вводу, лічильник згадок у бічній панелі.
- Мітки файлу: «Підозріле», «Перевірено», «Підробка», «Потребує перевірки» («Перевірено» і «Підробка» взаємовиключні).
- Журнал дій: завантаження, зміни, відкати, скачування, коментарі, мітки — хто і коли.
- Оновлення в реальному часі через SSE: нові коментарі, мітки й версії від інших з'являються без перезавантаження. Якщо в тебе є незбережені зміни, а хтось інший зберіг нову версію, буде запропоновано оновити, а не перезаписано тихо.

## Глибокий аналіз форматів

Окрім ExifTool, кожен файл проходить через форматні екстрактори. Їхні результати потрапляють і в окремі картки, і в таблицю (групи `FFprobe`, `Office`, `PDFScan`, `Structure`), тож працюють пошук, ризики й коментарі до полів.

| Формат | Що шукаємо |
|---|---|
| Відео / аудіо | контейнер, потоки й кодеки, теги (зокрема геолокація з телефонів), ознаки перекодування |
| DOCX / XLSX / PPTX / ODF | рецензенти, коментарі, виправлення в режимі рецензування (видалений текст), приховані аркуші, нотатки доповідача, макроси, зовнішні посилання й локальні шляхи шаблонів, EXIF/GPS вкладених зображень |
| PDF | `/JavaScript`, `/OpenAction`, `/Launch`, вкладені файли, форми, посилання, замасковані `#`-імена, інкрементні оновлення; стиснуті потоки розпаковуються |
| Зображення | вбудовані превʼю (Thumbnail/Preview/JpgFromRaw), порівняння з основним зображенням — показує обрізання чи ретуш |
| Будь-який | дані після логічного кінця файлу (JPEG/PNG/PDF/MP4/ZIP), дані перед ZIP-архівом; hex-переглядач |

Захист: розпаковування ZIP і PDF-потоків має ліміти розміру, XML-сутності не розгортаються, ffprobe запускається без shell з тайм-аутом.

Тестові файли для всіх форматів: `node samples/make-sample.mjs && node samples/make-deep-samples.mjs` → `samples/deep/`. Швидка перевірка без сервера: `cd apps/server && npx tsx scripts/deep-check.ts ../../samples/deep/*`.

Файли, завантажені до цього етапу, отримають глибокий аналіз після «Переаналізувати».

## Редагування

Кожна зміна — це список операцій:

```json
{ "ops": [
  { "kind": "preset", "preset": "all" },
  { "kind": "set", "tag": "Copyright", "value": "© Олена Коваль" },
  { "kind": "delete", "tag": "ExifIFD:SerialNumber" },
  { "kind": "shiftDates", "by": "+1:30" },
  { "kind": "setGps", "lat": 49.8397, "lon": 24.0297 }
] }
```

- Оригінал ніколи не змінюється: кожне збереження створює нову версію (`v2`, `v3`…), відкат — це теж нова версія.
- «Переглянути й зберегти» спершу застосовує зміни до тимчасової копії й показує точний diff.
- Операції виконуються по порядку: «прибрати все, потім задати копірайт» працює як очікується.
- Пресети: `all`, `gps`, `personal`, `keepCopyright`. Колірний профіль і орієнтація зберігаються.
- Файл, у якого розширення не відповідає вмісту (JPEG як `.png`), редагується за справжнім типом.
- Обмеження: PDF ExifTool змінює інкрементально — старі значення фізично лишаються у файлі.

## Офлайн-інструмент: таємне повідомлення в фото

`tools/secret-image.html` — окрема сторінка, яка працює без сервера: досить відкрити файл у браузері.

- Шифрує текст паролем (AES-256-GCM, ключ з пароля через PBKDF2-SHA-256, 200 000 ітерацій) і ховає одним із трьох способів: у молодших бітах пікселів фото (LSB), у невидимих символах нульової ширини всередині звичайного тексту або просто як зашифрований текст.
- Витягує й розшифровує повідомлення, якщо знаєш пароль.
- Має простий детектор: рахує частку одиничних бітів у LSB по кожному каналу і порівнює початок зображення з рештою.
- Усе відбувається в браузері, нічого не надсилається в мережу.
